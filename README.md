# FormalMathIntro2026

A repository for the course MS-EV0029 Introduction to Formalized Mathematics in Lean at Aalto University, Fall 2026.

 * `ProblemSets/` folder contains the homework problem sets.
 * `Demo/` folder contains various demonstrations from the lectures.
 * `ImperialCollegeExercises/` contains Kevin Buzzard's and Bhavik Mehta's
   exercise sheets of _Formalising mathematics_ taught at Imperial College
   London, from repository <https://github.com/b-mehta/formalising-mathematics-notes> 
   bumped to this repository's Lean and Mathlib version.
