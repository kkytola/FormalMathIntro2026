# Imperial College London exercise sheets by Kevin Buzzard and Bhavik Mehta

This folder contains the exercise sheets of the 2026 Imperial College London
course *Formalising mathematics*, bumped to the Lean and Mathlib version v4.34.0-rc2
used in the present course from Bhavik Mehta's original repository:
<https://github.com/b-mehta/formalising-mathematics-notes>.

The 2026 Imperial College London course was taught by Bhavik Mehta, and the exercise
sheets are by Kevin Buzzard and Bhavik Mehta, each file under the Apache 2.0 license.
